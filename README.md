# SEO/GEO Link Finder

**找网站、找邮箱、写邮件、追报价，一条流程接起来。**

**简体中文** | [English](README.en.md)

做外链合作，最费时间的往往是前面的杂活：搜一批网站，翻联系方式，逐封写询价，再回邮箱找回复。

这个项目把这些步骤交给 AI 助手处理。你提供网站、目标市场和预算，确认发件身份与发送范围后，让它继续找合作方、发邮件、整理回复。最后，你可以直接查看哪些网站愿意合作、报价多少、条件是什么。

```text
你的网站 + 目标市场 + 预算
            ↓
找相关网站 → 筛选质量 → 找合作邮箱 → 写信询价 → 跟进回复
            ↓
合作名单、报价、发布条件和联系记录
```

## 它能替你做什么

- **找一批有理由联系的网站。** 看主题是否相关、流量是否达标、有没有合作入口，并留下来源，方便回查。
- **先确认谁负责合作。** 从公开页面找编辑、广告或商务邮箱，筛掉招聘、客服等不相关的联系人。
- **给不同网站写不同的信。** 用查到的栏目和合作信息切入，询问价格、链接规则和发布时间；发送前检查签名、重复文案和不该透露的客户信息。
- **把回信变成能用的结果。** 记录报价、免费投稿机会、拒绝和退信。对方转介绍新联系人时，也能接着处理；收到回复或退出要求后停止催信。

适合做独立站 SEO、海外内容合作，或替客户寻找投稿与赞助机会的人。

## 最后拿到什么

一份能继续推进合作的清单：

| 你关心的事 | 结果里有什么 |
| --- | --- |
| 这个网站为什么值得联系？ | 相关性、筛选依据和来源链接 |
| 联系到哪一步了？ | 已发送、待回复、已报价、拒绝、退信等状态 |
| 要花多少钱？ | 回复中给出的价格、币种，或确认的免费投稿渠道 |
| 发布有什么条件？ | 链接属性、保留时间、发布周期和内容要求，按已收到的信息记录 |
| 哪些还需要我判断？ | 缺失条款、异常回复和风险提示 |

结果可保留为 JSON；配置好表格运行环境后，也可导出 Excel。

## 可以这样交代任务

> 为我的网站寻找面向英语市场的行业媒体。先筛选 30 个适合联系的网站，单个合作预算不超过 100 美元。准备好询价邮件，先让我看；确认后再发送，并整理后续报价。

开始前，助手会核对你的目标、邮箱和署名。默认先准备、后发送；你也可以在明确授权后让它按约定范围自动外联和跟进。

**实际收发邮件需要连接 Gmail 的 AI 助手环境；持续跟进还需要计划任务支持。** 本仓库提供 Skill 和配套脚本，下载后单独运行 Python 不会自动发邮件。

## 开始使用

```bash
git clone https://github.com/z992907759/seo-geo-link-finder.git
cd seo-geo-link-finder

# 先运行本地测试，无需邮箱或付费 API
python3 -m unittest discover -s tests -v

# 创建自己的任务配置
mkdir -p campaigns/my-campaign
cp assets/campaign-brief.example.json campaigns/my-campaign/campaign.json
```

需要 **Python 3.10+**，Python 部分仅使用标准库。编辑配置中的网站、市场和预算，再将 [SKILL.md](SKILL.md) 交给支持该工作流的助手，按里面的步骤连接 Gmail、确认发件身份并准备数据。

想先看脚本入口，可以运行 `python3 scripts/pipeline.py --help`。完整输入格式见 [数据说明](references/data-contract.md)。

<details>
<summary>可选配置：流量数据与 Excel 导出</summary>

### DataForSEO

网站检索与流量估算可使用 DataForSEO。需自行提供账号，API 调用可能收费。

配置环境变量 `DATAFORSEO_LOGIN` 和 `DATAFORSEO_PASSWORD`；macOS 也可从 Keychain 的 `seo-geo-link-finder-dataforseo` 服务读取对应登录名的密码。脚本不会自动加载 `.env` 文件。

### Excel

表格脚本需要 Node.js 和运行环境提供的 `@oai/artifact-tool`。仓库不附带该依赖，也不保证可从公共 npm 安装。缺少它时，可以先使用 Python 脚本和 JSON 结果。

## 你的数据留在自己的任务里

公开仓库只包含代码、说明和示例，不包含实际客户名单、邮箱账号、邮件记录或历史报价。`campaigns/`、`outputs/`、常见凭据和任务状态文件已加入 `.gitignore`；上传自己的改动前，仍应检查新增文件。

助手负责找到机会、收集回复和报价。选哪家、是否购买、是否接受条款，由你决定。外联需遵守邮箱服务商规则，并尊重收件人的退出要求。
